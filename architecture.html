NFT 上鏈鑄造流程

從 Admin 點擊到鏈上確認，7 個階段
1
Admin 填寫鑄造表單
系列 / 編號 / 年份 / 稀有度 / 接收地址 / 屬性 Traits
2
構建 ERC-721 Metadata JSON
符合 OpenSea Metadata Standard，包含 image / attributes / properties
{ "name": "RTEAK #18421", "attributes": [...] }
3
上傳至 IPFS / Arweave
Pinata 服務固定 metadata，獲取 CID
ipfs://QmYwAPJzv5...18421.json
4
建立鏈上交易
呼叫 NFT Factory 合約的 safeMint 方法
safeMint(address to, uint256 tokenId, string uri)
5
多簽簽名 (3/5)
關鍵操作需要至少 3 位管理員多簽通過
Multisig 0xMu1tiSig...A4d2C0
6
廣播至 Polygon RPC
Submit raw transaction，等待礦工打包
Gas: 0.0142 MATIC · Block time ~2.5s
7
區塊確認 + 寫入稽核日誌
通知接收者 + 同步到用戶端二級市場 + 寫入論壇公告
✓ Tx: 0xa1b2..f3e4 · Block #52,840,193

核心資料流

用戶 ↔ 平台 ↔ 鏈上的完整路徑

📥 充值入金流程

用戶 → [信用卡 / 銀行 / C2C] ↓ 法幣支付閘道（Stripe / MoonPay） ↓ USDC / USDT 鑄造 → 平台金庫 ↓ 寫入用戶錢包餘額 ↓ 通知 + Toast 提示

🛒 NFT 二級市場交易

買家點擊「立即購買」 ↓ Marketplace 合約 buyNow(tokenId) ↓ USDC 從買家轉賣家（扣 2% 手續費） ↓ NFT ownerOf 變更 + 觸發 Transfer 事件 ↓ Indexer 同步至前端 ↓ 更新雙方持倉 + 寫入活動 feed

💰 提領出金流程

用戶提交提領申請 ↓ 風險評分（地址新舊 / 金額 / 行為） ↓ > $10K → Admin 審核佇列 ↓ 管理員批准（多簽） ↓ 合約 transfer 至用戶外部錢包 ↓ 寫入稽核日誌 + 通知

💬 論壇 ↔ 站內信聯動

用戶發布求購貼文 ↓ 其他用戶點「✉️ 私訊作者」 ↓ 自動建立對話 + 跳轉 page-messages ↓ 即時聊天（每則訊息 1.5–4s 對方自動回覆） ↓ 未讀數同步至 Header 紅點 ↓ 達成交易後可進入合約託管
